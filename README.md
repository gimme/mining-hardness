# Mining Hardness

Makes mining more difficult by adding depth-based hardness.

Note: the mod has to be installed on both the client and server with matching configurations.

## Features
- Deeper blocks get progressively harder to mine:
  - It takes longer
  - It's more exhausting (hunger)
  - Tools lose durability faster

The intent is to make mining a more strategic activity. The deeper you go, the more incentivized you are to explore caves instead of digging in safety.
